# Levshitsky — сайт ателье и техцентра

Статичный сайт без сборки: `index.html`, `css/`, `js/`, `img/`, `video/`, `fonts/`.

- Открыть локально: `python3 -m http.server` в папке проекта, затем http://localhost:8000
- Тексты и подписи карточек: `js/content.js`, данные проектов и журнала: `js/data.js`
- Шрифты: Fira Sans Extra Condensed (заголовки) и Montserrat (текст)
- Цвета: белый, чёрный, красный #D5121E

Заявки и чат ассистента пока работают в демо-режиме: отправка на сервер не подключена.
Фото техцентра и проектов — визуализации.
